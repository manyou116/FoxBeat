# FoxBeat v0.1.5 · 跳跳狐与散味舞

新增第九位舞伴「跳跳狐」和专属「散味舞」。内置待机图及 18 张透明动画帧，使用原比例绘制，无需运行时联网。

- 每次有效按键、鼠标点击或滚轮事件推进一帧，18 帧循环。停手 2 秒恢复待机，再次输入从第一帧开始。
- 复用 FoxBeat 的窗口、拖动、托盘、设置和原生输入监听。拖动期间保持当前姿势，结束后恢复计时。
- 主题中心支持点击、键盘、滚轮试玩，以及一键开启三种全局输入来源。切换角色保留原输入开关和其他角色的舞蹈模式。
- 防止桌面点击与原生监听重复计数，试玩输入转发也根据来源去重。高速输入沿用原生层每批最多 256 次的防积压限制。
- 修复逐帧超时后、尚未绘制待机时收到下一次输入的重置问题，并预加载舞蹈图片。

更新后，在主题中心选择「跳跳狐 · 散味舞」，点击「应用到桌面」。要跟随三种操作，再点击「开启键盘、点击和滚轮跟随」。

这是开发预览版。安装包和 OTA 文件由 GitHub Actions 在三个平台完成构建与自动测试后发布；macOS 的系统输入权限、不同缩放与多屏拖动仍需实机验收。
